My AI safety projects

CHANAKYA

Ongoing

A tool I'm building to catch broken access control in code, the kind of bug where one user can see or change someone else's data. AI coding assistants make this mistake a lot. CHANAKYA gathers evidence from the code first and only then lets an AI look into it, so every finding points back to real lines of code. I'm starting with Java and Spring.

SafetyBox

Ongoing

An experiment in keeping AI agents in line. The agent can think however it likes, but when it tries to actually do something, like delete a file or call an API, SafetyBox checks that action against what the task allows before letting it through. I test it with cases built to push the agent into misbehaving.
